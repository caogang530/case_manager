# Branch 用例画布

Branch 是一个本地用例管理工作台。通过左侧栏切换用例库和测试计划，在列表中打开文档后直接编辑导图。

## 本地启动

安装 Node.js 和 npm 后，在仓库根目录运行以下脚本。

```sh
./start.sh
```

脚本会在首次运行或依赖清单更新后安装依赖。启动后打开 `http://127.0.0.1:8794/`。首次打开会显示示例用例库和测试计划。按 `Ctrl+C` 停止服务。

## 生产构建

```sh
npm run build
npm run preview
```

构建产物位于 `branch/dist`。预览地址由终端输出。

## 画布操作

- 双击节点编辑标题。选中节点后，按 `Tab` 添加子节点，按 `Enter` 添加同级节点。拖动节点到模块上可移动分支。
- 拖动空白处平移，按住 `⌘` 或 `Ctrl` 滚动缩放。也可以通过小地图定位，或折叠分支。
- 搜索按标题定位。按 `Enter` 或 `Shift+Enter` 浏览匹配结果。测试计划支持按状态和优先级筛选。
- 点击节点的状态按钮选择结果。用 `⌘/Ctrl+点击`、`Shift+点击` 或 `Shift+拖动空白处` 可以多选和批量标记。
- 计划从用例库建立独立快照。编辑会自动保存在当前浏览器和访问地址对应的 IndexedDB 中。可通过 XMind 导入和导出文档。

`test-case.xmind` 和 `test-image.xmind` 分别是普通用例和含图片的导入示例。
