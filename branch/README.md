# Branch 用例画布

在仓库根目录运行 `npm run branch:dev`，打开 `http://127.0.0.1:8794/`。首次打开会显示一份示例用例库和测试计划。

- 双击节点编辑标题。选中节点后，按 `Tab` 添加子节点、按 `Enter` 添加同级节点。拖到模块上可移动分支。
- 拖动空白区平移，按住 `⌘` 或 `Ctrl` 滚动可缩放。触屏可用双指缩放。小地图可以拖动视口，模块节点右侧可以折叠分支。
- 搜索按标题定位，并保留祖先分支。用 `Enter` 和 `Shift + Enter` 切换匹配。测试计划还可以按执行状态和优先级过滤。
- 点击节点状态图标选择结果。用 `⌘/Ctrl + 点击`、`Shift + 点击` 或 `Shift + 拖空白` 选择多条用例后批量标记。
- 在用例库的文档菜单中创建测试计划。计划从用例库生成独立快照。XMind 文件可作为交换和备份格式。

编辑结果自动保存在当前浏览器的 IndexedDB 中。浏览器配置文件和访问地址各自有独立的工作区。生产构建运行 `npm run branch:build`，输出到 `branch/dist`。
